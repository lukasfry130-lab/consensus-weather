# Consensus Weather

A weather app that blends up to 18 forecast models and agencies (ECMWF, NOAA GFS/NBM/HRRR/RRFS/AI-GFS, the National Weather Service, UK Met Office, DWD ICON, Environment Canada, Météo-France, JMA, KMA, BOM, CMA, MET Norway) into one consensus forecast, plus a 16-day ensemble outlook. Wind arrows point the way to ride for a tailwind.

Live at: https://lukasfry130-lab.github.io/consensus-weather/
